## 定期実行

- 月初：毎月1日、日本時間の朝に発表済み開催予定を更新するタスクを設定済みにゃ。
- リンク：毎日23:59 Asia/Tokyo に完成・公開確認だけを行うタスクを設定済みにゃ。
- GitHub Actions 側には新しい定期実行を追加しないにゃ。既存のmain push時の公開経路を利用するにゃ。
- `maintenance/update_schedule.py` は公式HTMLをメモリ内で検証し、正規化した表示項目だけ保存するにゃ。
- `maintenance/update_links.py` は公開HTMLをメモリ内で検証し、URL・最終レース・ハッシュだけ保存するにゃ。元HTMLは保存しないにゃ。
- ネットワーク制限時は、未確認の日程やリンクを推測で追加せず、現状を保持するにゃ。

- `index.html` は日本時間の今月を初期表示するにゃ。`202611.html` などの月別ページは固定した月を表示するにゃ。更新時は `python3 site/calendar/maintenance/build_months.py` で発表済みの月別ページをそろえるにゃ。
